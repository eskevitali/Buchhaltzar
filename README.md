# Buchhaltzar

Buchhaltzar — локальное мобильное приложение бухгалтерского учёта, реализованное как плагин Obsidian. Obsidian Vault является основным хранилищем, а каждая подтверждённая операция сохраняется как отдельный Markdown-файл.

Документация проекта:

- [SPEC.md](./SPEC.md) — техническое задание и продуктово-архитектурная спецификация.
- [DEPLOYMENT.md](./DEPLOYMENT.md) — сборка, тестирование, установка, выпуск и эксплуатация.
- [SERVER-DEPLOY.md](./SERVER-DEPLOY.md) — подготовка и размещение установочного пакета на сервере.

Статус: MVP 0.9.0. Рабочий срез включает инициализацию чистого vault, системные счета, приход, основной приход, расход, ручное разделение расхода, перевод, сторно, балансы, журнал, архивные отчёты и необязательный сетевой слой для голоса и чеков. Интерфейс использует фирменную визуальную систему Lokvita.

Ручной учёт полностью работает без сети. Сетевые функции включаются отдельно: голос, текст команды или выбранную фотографию чека обрабатывает OpenAI. Для чека распознаются только общая сумма и основные реквизиты; товарные позиции не извлекаются.

При проведении распознанного чека его оригинал сохраняется в `Receipts/YYYY/MM/`, а транзакция получает поле `receiptPath`. Отмена черновика не создаёт файл чека.

Команда «Разделить расход» позволяет вручную ввести одну или несколько выделенных сумм и выбрать для каждой счёт списания. Интерфейс сразу уменьшает остаток к распределению. Нераспределённый остаток проводится по основному счёту, а все части сохраняются одной сбалансированной многосчётной транзакцией.

Раздел «Архивный отчёт» формирует отчёт за неделю, месяц, квартал или год. Один период сохраняется одним Markdown-файлом в `Reports/`: в нём есть общий денежный результат, движение по каждому счёту и таблица всех транзакций со ссылками на исходные записи и чеки. Повторное формирование того же периода обновляет тот же файл.

Каталог `Notes/` предназначен для любых дополнительных заметок пользователя. При первом запуске добавляются поставляемые с плагином заметки `Почему учёт называется царским.md`, `GraviTON — краткая аннотация.md` и `GraviTON_ КОН и архитектура хозяйственной системы.md`, а в корне создаётся подробный файл `Добро пожаловать.md`. Плагин не учитывает заметки как транзакции и никогда не перезаписывает уже существующие файлы.

## Разработка

```bash
pnpm install
pnpm check
pnpm test
pnpm build
```

## Установка

Пакет 0.9.0:

- библиотека Lokvita: https://lokvita.org/library/buchhaltzar
- GitHub: https://github.com/eskevitali/Buchhaltzar

**Компьютер.** Распакуйте ZIP и запустите `install.sh` (Linux/macOS) или `install.ps1` (Windows). Установщик находит хранилища Obsidian, копирует плагин и отмечает его для включения. Затем откройте выбранный vault и при необходимости разрешите сторонние плагины.

**Телефон.** В файловом менеджере покажите скрытые файлы и скопируйте из архива папку `buchhaltzar` в `.obsidian/plugins/` хранилища.

Не ставьте в основной рабочий vault, пока не сделана резервная копия. Подробности — в `Установка.txt` внутри ZIP.

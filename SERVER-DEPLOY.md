# Размещение серверного релиза Buchhaltzar

Готовый каталог создаётся командой:

```bash
pnpm release:server
```

Результат находится в `dist/server/buchhaltzar/`.

## Содержимое

- `<version>/main.js` — производственная сборка плагина;
- `<version>/manifest.json` — манифест той же версии;
- `<version>/styles.css` — стили интерфейса;
- `buchhaltzar-<version>.zip` — те же три файла в одном архиве;
- `latest.json` — машиночитаемое описание актуальной версии;
- `versions.json` — соответствие версий плагина минимальной версии Obsidian;
- `SHA256SUMS` — контрольные суммы всех публикуемых файлов.

В серверный каталог не входят исходный код, тестовые данные, транзакции, отчёты, чеки и пользовательский `data.json` с настройками или API-ключом.

## Публикация

Загрузите каталог `dist/server/buchhaltzar/` целиком в постоянный публичный путь сервера, например:

```text
https://example.org/plugins/buchhaltzar/
```

Установщик может прочитать `latest.json`, проверить `version` и `minAppVersion`, скачать ZIP либо три отдельных файла из каталога, указанного в `releasePath`, проверить SHA-256 и поместить их в:

```text
<Vault>/.obsidian/plugins/buchhaltzar/
```

После копирования пользователь включает Buchhaltzar в разделе сторонних плагинов Obsidian. При первом запуске плагин создаёт отсутствующие каталоги и встроенные документы, не перезаписывая существующие файлы.

Для выпуска новой версии сначала измените версию в `manifest.json`, `package.json` и `versions.json`, затем повторно выполните производственную сборку и упаковку. Не заменяйте содержимое уже опубликованного каталога старой версии: это сохраняет воспроизводимость установки.
